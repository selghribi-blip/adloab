# اختبار الحمل (لمواقعك فقط)

جناح اختبار حمل بمسارين: **k6** (المعيار الصناعي) و**بديل asyncio** يعمل بلا أي تثبيت.

> ⚠️ حدود الاستخدام: كل الأوامر تمرّ عبر **حاجز الملكية** نفسه المستخدم في المراقبة —
> أي نطاق غير مدرج في `config/owned_domains.yaml` يُرفض فورًا (كود خروج 2).
> اختبار الحمل على موقع لا تملكه يُعدّ هجوم حجب خدمة (DoS) ومعاقب عليه قانونًا،
> ويخالف شروط استخدام مزوّدي الاستضافة. اختبر **نسخة staging** لا الإنتاج.

---

## 1) البديل السريع (بلا تثبيت)

```bash
python loadtest/py_load.py \
  --url http://127.0.0.1:8000/healthz \
  --vus 20 --duration 30 --i-own-this-site
```

نتيجة حقيقية من تشغيل هذا السيناريو على اللوحة داخل هذه البيئة:

```
إجمالي الطلبات      : 11088
معدّل الطلبات       : 553.8 طلب/ثانية
نسبة الأخطاء        : 0.0%
الذروة p95          : 107.4 ms
الذروة p99          : 168.7 ms
أبطأ طلب            : 373.4 ms
✅ كل الحدود محترمة — الأداء مقبول تحت هذا الحمل.
```

خيارات مفيدة: `--think-time 1` (محاكاة مستخدم يتصفّح فعلًا)، `--max-p95`, `--max-error-rate`,
و`--timeout`. يرجع كود خروج 1 عند تجاوز أي حد — مثالي لخط CI.

## 2) مسار k6

```bash
python loadtest/run.py --url https://staging.mysite.ma \
  --scenario load --vus 30 --duration 2m --i-own-this-site
```

- يتحقق من الملكية أولًا، ثم يبحث عن k6 في `PATH`، وإن لم يجده ينزّله من إصدارات GitHub
  عند تمرير `--install-k6`.
- السيناريوهات: `smoke` (5 طلبات)، `load` (تصاعد تدريجي + ثبات)، `stress` (بحث عن نقطة الانهيار).
- يطبع ملخّصًا عربيًا من ملف k6 ويترجم تجاوز الحدود إلى كود خروج 1.
- الحدود قابلة للضبط: `MAX_P95`, `MAX_P99`, `MAX_ERROR_RATE` (متغيرات بيئة).

## 3) في CI (مجانًا)

`.github/workflows/loadtest.yml`:

| المهمة | متى تعمل | الوصف |
|---|---|---|
| `self-load-test` | كل push | يشغّل اللوحة ثم يحمّلها بـ 20 مستخدمًا و20 ثانية — تحقّق انحدار تلقائي |
| `target-load-test` | يدويًا فقط | على موقعك، بعد تأكيد `i_own_this_site = yes` |
| `refuse-without-confirmation` | يدويًا بلا تأكيد | يفشل برسالة تشرح السبب |

## تفسير النتائج

| المؤشر | المعنى | ما تفعله إن كان سيئًا |
|---|---|---|
| `p95` | 95% من الطلبات أسرع من هذه القيمة | افحص استعلامات قاعدة البيانات وأضف فهرسة |
| `p99` / `max` | ذيل التوزيع: الطلبات البطيئة الشاذة | ابحث عن أقفال (locks) أو استدعاءات خارجية متزامنة |
| نسبة الأخطاء | طلبات 5xx أو فاشلة | راجع سجلات السيرفر وعدد العمال (workers) |
| معدّل الطلبات/ثانية | الإنتاجية الفعلية | زد عدد العمال أو أضف تخزينًا مؤقتًا (cache) |

## ملاحظة عن GitHub Actions

على المستودعات العامة، دقائق Actions مجانية — بما يكفي لتشغيل اختبار حمل صغير عند كل
تعديل. اختبارات الحمل الثقيلة استخدمها عند الحاجة فقط (وليس عند كل push) لتوفير الحصة.
